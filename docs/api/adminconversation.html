create

POST /admin.conversations.create

Operation ID: admin_conversations_create.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | token | header | any | Yes | Authentication token. Requires scope: admin.conversations:write | | name | formData | any | Yes | Name of the public or private channel to create. | | description | formData | any | No | Description of the public or private channel to create. | | is_private | formData | any | Yes | When true, creates a private channel instead of a public channel | | org_wide | formData | any | No | When true, the channel will be available org-wide. Note: if the channel is not org_wide=true, you must specify a team_id for this channel | | team_id | formData | any | No | The workspace to create the channel in. Note: this argument is required unless you set org_wide=true. |

Responses

200: Typical success response
default: Typical error response

list

GET /admin.conversations.search

Operation ID: admin_conversations_search.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | token | header | any | Yes | Authentication token. Requires scope: admin.conversations:read | | team_ids | query | any | No | Comma separated string of team IDs, signifying the workspaces to search through. | | query | query | any | No | Name of the channel to query by. | | limit | query | any | No | Maximum number of items to be returned. Must be between 1 - 20 both inclusive. Default is 10. | | cursor | query | any | No | Set cursor to next_cursor returned by the previous call to list items in the next page. | | search_channel_types | query | any | No | The type of channel to include or exclude in the search. For example private will search private channels, while private_exclude will exclude them. For a full list of types, check the Types section. | | sort | query | any | No | Possible values are relevant (search ranking based on what we think is closest), name (alphabetical), member_count (number of users in the channel), and created (date channel was created). You can optionally pair this with the sort_dir arg to change how it is sorted | | sort_dir | query | any | No | Sort direction. Possible values are asc for ascending order like (1, 2, 3) or (a, b, c), and desc for descending order like (3, 2, 1) or (c, b, a) |

Responses

200: Typical success response
default: Typical error response
