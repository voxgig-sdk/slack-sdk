GET /users.conversations

Operation ID: users_conversations.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | token | query | any | No | Authentication token. Requires scope: conversations:read | | user | query | any | No | Browse conversations by a specific user ID's membership. Non-public channels are restricted to those where the calling user shares membership. | | types | query | any | No | Mix and match channel types by providing a comma-separated list of any combination of public_channel, private_channel, mpim, im | | exclude_archived | query | any | No | Set to true to exclude archived channels from the list | | limit | query | any | No | The maximum number of items to return. Fewer than the requested number of items may be returned, even if the end of the list hasn't been reached. Must be an integer no larger than 1000. | | cursor | query | any | No | Paginate through collections of data by setting the cursor parameter to a next_cursor attribute returned by a previous request's response_metadata. Default value fetches the first "page" of the collection. See pagination for more detail. |

Responses

200: Typical success response with only public channels. Note how num_members and is_member are not returned like typical conversations objects
default: Typical error response
