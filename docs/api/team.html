GET /team.integrationLogs

Operation ID: team_integrationLogs.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | token | query | any | Yes | Authentication token. Requires scope: admin | | app_id | query | any | No | Filter logs to this Slack app. Defaults to all logs. | | change_type | query | any | No | Filter logs with this change type. Defaults to all logs. | | count | query | any | No | | | page | query | any | No | | | service_id | query | any | No | Filter logs to this service. Defaults to all logs. | | user | query | any | No | Filter logs generated by this user’s actions. Defaults to all logs. |

Responses

200: Typical success response
default: Typical error response
