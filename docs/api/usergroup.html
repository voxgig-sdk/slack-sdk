POST /usergroups.update

Operation ID: usergroups_update.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | handle | formData | any | No | A mention handle. Must be unique among channels, users and User Groups. | | description | formData | any | No | A short description of the User Group. | | channels | formData | any | No | A comma separated string of encoded channel IDs for which the User Group uses as a default. | | token | header | any | Yes | Authentication token. Requires scope: usergroups:write | | include_count | formData | any | No | Include the number of users in the User Group. | | usergroup | formData | any | Yes | The encoded ID of the User Group to update. | | name | formData | any | No | A name for the User Group. Must be unique among User Groups. |

200: Typical success response
default: Typical error response
