POST /admin.users.invite

Operation ID: admin_users_invite.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | token | header | any | Yes | Authentication token. Requires scope: admin.users:write | | team_id | formData | any | Yes | The ID (T1234) of the workspace. | | email | formData | any | Yes | The email address of the person to invite. | | channel_ids | formData | any | Yes | A comma-separated list of channel_ids for this user to join. At least one channel is required. | | custom_message | formData | any | No | An optional message to send to the user in the invite email. | | real_name | formData | any | No | Full name of the user. | | resend | formData | any | No | Allow this invite to be resent in the future if a user has not signed up yet. (default: false) | | is_restricted | formData | any | No | Is this user a multi-channel guest user? (default: false) | | is_ultra_restricted | formData | any | No | Is this user a single channel guest user? (default: false) | | guest_expiration_ts | formData | any | No | Timestamp when guest account should be disabled. Only include this timestamp if you are inviting a guest user and you want their account to expire on a certain date. |

Responses

200: Typical success response
default: Typical error response
