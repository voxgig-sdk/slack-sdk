GET /oauth.access

Operation ID: oauth_access.

Authentication: oauth2 (slackAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | client_id | query | any | No | Issued when you created your application. | | client_secret | query | any | No | Issued when you created your application. | | code | query | any | No | The code param returned via the OAuth callback. | | redirect_uri | query | any | No | This must match the originally submitted URI (if one was sent). | | single_channel | query | any | No | Request the user to add your app only to a single channel. Only valid with a legacy workspace app. |

200: Successful user token negotiation for a single scope
default: Typical error response
